Getting started

Open any text or code file, or choose File → Open Folder… to browse a project in the sidebar. Press ⇧⌥⌘P for the command palette: every command is there.

Useful shortcuts

⇧⌘O Open Quickly · ⌘F Find · ⌥⌘F Replace · ⇧⌘F Find in Folder · ⌘D Add next occurrence · ⌘/ Toggle comment · ⌥⌘C Column editor · ⌃⇧R Record macro · ⌃⌘T Split editor

A file shows strange characters

Click the encoding in the status bar and choose Reopen With Encoding.

Highlighting for an unknown file type

Choose View → Language → Define Your Own Language… to add keywords, comments and strings for it.

Changing shortcuts

Use System Settings → Keyboard → Keyboard Shortcuts → App Shortcuts. Any menu command can be given a new shortcut.

Requirements

A Mac with Apple Silicon running macOS 14 or later.

Comparing files and folders

Choose Tools → Compare → Compare Folders… to compare two folders, then double-click a file to see its differences side by side. Copy single changes or whole files from one side to the other; ⌘Z undoes.
